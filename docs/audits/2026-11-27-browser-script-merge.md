# Browser script merge, 2026-11

Prompt `prompts/dx/01` gave every browser console script one canonical file in
`browser/`. Before it, the same tool often lived in two to four of `browser/`,
`scripts/`, `scripts/twitter/` and `src/automation/` with different code. This
records what was decided for each tool, so a reviewer can find every ported
feature in the canonical file and every default that changed.

Rules applied to every merge:

- **Base:** the member that did more and was newer. Every behaviour only another
  member had was ported into it, optional behaviour behind a `CONFIG` option
  that defaults to off.
- **Safety defaults:** where members disagreed on a dry run, a confirmation, a
  cap or a delay, the canonical takes the safest, because every old path now
  runs the canonical file. A user of a path that used to dry-run by default
  does not get live actions.
- **Old paths:** each member path is a generated copy of the canonical file
  (`npm run browser:build`), listed in its `@aliases` header tag.
- **Core:** canonical files built from `src/automation/` scripts use
  `window.XActions.Core` when it is loaded and built-in fallbacks when not.

97 merges and 61 single-file moves (copied to `browser/` with a header, old path kept as a copy).
